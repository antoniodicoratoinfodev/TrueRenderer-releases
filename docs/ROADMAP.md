# Roadmap di distribuzione

- Aggiungere il pacchetto Windows in una consegna successiva, con istruzioni e verifiche sul sistema nativo.
- Qualificare installazione, aggiornamento e compatibilità macOS su macchine pulite.
- Preparare firma Developer ID, notarizzazione, distinta dei componenti e condizioni d'uso per un eventuale rilascio pubblico.

Priorità indicative, senza date promesse. Il repository ospita la distribuzione pubblica; lo sviluppo del codice avviene in un repository privato.
